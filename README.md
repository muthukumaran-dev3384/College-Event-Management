🎓 College Event Registration System

📌 Overview

The College Event Registration System is a web-based application developed to simplify and automate the management of college events, student registrations, and payment tracking. The system provides a centralized platform for Administrators, Department Organizers, and Students to manage event-related activities efficiently.

The application eliminates manual registration processes, reduces paperwork, improves data accuracy, and provides real-time event management through a secure and user-friendly interface.

---

🚀 Features

👨‍💼 Admin Module

- Secure Admin Login
- Manage Department Organizers
- Bulk Student Account Creation
- View and Monitor All Events
- Track Student Registrations
- View Paid Event Payment Details
- Generate Reports and Analytics
- Manage System Activities

👨‍🏫 Organizer Module

- Secure Organizer Login
- Create and Manage Events
- Add Event Details (Date, Time, Venue, Fee)
- Manage Event Status (Open/Closed)
- View Registered Students
- Download Registration Reports
- Track Event Participation

👨‍🎓 Student Module

- Secure Student Login
- View Available Events
- Register for Free and Paid Events
- Upload Payment Proof for Paid Events
- View Registration History
- Download Uploaded Payment Proof
- Access Event Information

⚙️ Installation

1. Clone the repository

git clone https://github.com/your-username/college-event-registration-system.git

2. Move the project to the XAMPP htdocs folder.

3. Start Apache and MySQL.

4. Import the database file into MySQL using phpMyAdmin.

5. Configure database credentials in:

db.php

6. Open the browser:

http://localhost/college-event-registration-system
